# casTelloPy

**casTelloPy** is an experimental Python project focused on controlling and interacting with the **DJI Tello** drone through a modular software architecture.  
It was developed as an advanced learning project, combining hardware control, real-time interaction, UI experimentation, and message-based state handling.

> ⚠️ This is a **legacy / experimental project**.  
> It is preserved for educational and portfolio purposes.

---

## Project Goals

The main objectives of casTelloPy were:

- Explore **drone control via Python**
- Design a **modular control architecture**
- Experiment with **input devices** (keyboard, gamepad)
- Handle **real-time messages, callbacks, and state**
- Test different interface and control approaches iteratively

---

## Key Features

- 🛩️ DJI Tello control abstraction
- 🎮 Gamepad and keyboard input handling
- 🧠 Message-based control logic
- 🖥️ GUI and interface experimentation
- 🧪 Exploratory test scripts
- 🔁 Multiple alternative implementations documenting evolution
